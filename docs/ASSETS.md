# 에셋 출처 및 라이선스

## 그래픽 — 100% 오리지널 (코드 생성)
게임 안의 모든 이미지는 외부 파일 없이 `src/game/art/` 의 코드가 실행 시 캔버스에 직접 그립니다.

| 파일 | 내용 |
|---|---|
| `pixel.ts` | 작은 픽셀 아트 엔진 (타원/선/자동 외곽선/그림자) |
| `characters.ts` | SD 캐릭터: 헤어 8종 × 머리색 8 × 피부 5 × 의상 4 × 옷 색 8, 4방향 × 4프레임 |
| `crops.ts` | 작물 10종 × 4단계, 수확물 아이콘 10종, 씨앗 봉투 10종 |
| `tiles.ts` | 잔디·흙길·광장 돌·물·나무다리 지형 (이웃 타일 기반 경계 블렌딩) |
| `buildings.ts` | 씨앗 상점, 농산물 판매소, 농장 집, 마을 집 3종 |
| `objects.ts` | 나무 5종, 덤불, 꽃 5색, 울타리, 벤치, 가로등, 게시판, 분수(애니메이션), 연꽃, 갈대, 출하 상자, 우편함, 허수아비, 나비 등 |
| `icons.ts` | 골드, 호미, 물뿌리개, 바구니, 가방 |

기존 게임(스타듀밸리, 동물의 숲 등)의 캐릭터·맵·그래픽을 복제하지 않았으며, 형태와 색은 이 프로젝트를 위해 새로 디자인했습니다.

## 효과음 — 100% 오리지널 (WebAudio 합성)
`src/audio/sfx.ts` 에서 오실레이터/노이즈로 실시간 합성합니다. 외부 사운드 파일 없음.
